# 魔法使いの夜 — 非公式Android移植版

[English](README.md) · [한국어](README.ko.md) · 日本語

画面サイズや縦横比の異なるスマートフォン・タブレット・折りたたみ端末に対応した、ネイティブAndroid移植版です。**PCなしでSteamのゲームを端末に直接インストールし、その後は完全にオフラインで遊べます。**

**[最新APKをダウンロード](https://github.com/david419kr/mahoyo-steam-android-port/releases/latest/download/mahoyo-unofficial.apk)**

## 必要なもの

- **魔法使いの夜**を所有するSteamアカウント
- Android 9以降、OpenGL ES 3.0に対応する64ビットARM端末
- ログイン・インストール用のインターネット接続と約**20GBの空き容量**。必要な容量はアプリに表示されます。

## Steamからインストール

1. 端末にAPKをインストールします。Androidで確認が出たら、APKを開いたアプリからのインストールを許可してください。
2. アプリを開き、**QRコードでログイン**するか、Steamアカウント名・パスワードとSteamガードでログインします。
3. 所有権の確認後、**Steamからダウンロード**を押します。
4. ダウンロードとゲームデータの準備が終わるまで待ちます。
5. **プレイ**を押します。

インストール後は、定期的なSteamへの再ログインなしで**完全にオフラインでプレイ**できます。ダウンロードが中断された場合は、再度ログインして**Steamからダウンロード**を選ぶと再開できます。

### 同じスマートフォンでSteam認証アプリを使う場合

ログイン用QRを別の画面に表示できます。

1. **別の端末にQRを表示**を押し、表示されたアドレスをPC・タブレット・別のスマートフォンのブラウザーで開きます。
2. 両方の端末を同じWi-Fi、または同じルーターの有線LANに接続します。
3. スマートフォンで**Steam認証アプリを開く**を押し、別の画面のQRを読み取ってログインを承認します。

QRは自動更新されます。共有ボタンの横にある**?**でも手順を確認できます。

## 操作方法

| 操作 | 動作 |
| --- | --- |
| タップ | 文章を進める |
| 2本指でタップ | メニューの表示・非表示 |
| 下にスワイプ | 履歴 |
| 上にスワイプ | 設定 |
| 右にスワイプ | セーブ |
| 左にスワイプ | ロード |
| 1秒間長押し | 指を離すまでスキップ |

各メニューは逆方向のスワイプで閉じられます。文章やメニューをスクロールできる場合は、端まで移動してからさらにスワイプしてください。開く途中で戻す方向に動かして指を離すと取り消せます。

**設定 → 画面**では、オリジナル16:9・可変レイアウト、画像の全体表示・画面に合わせる表示、全画面・下部パネルの文章表示を選べます。文章表示の**自動**は画面の空きに合わせて配置します。文字サイズや左右の余白も調整できます。

セーブは端末内に保存されます。アプリのアンインストールやストレージの消去で、インストールデータとセーブも削除されます。

ゲームの制作・販売元およびValveとは関係のない非公式プロジェクトです。ゲームファイルはご自身のSteamアカウントでダウンロードします。

## 上級者向け：OBBの取り込み

Steamでの所有権確認後、インストール画面からPCで変換した約**5GBのAVIF OBB**を取り込むこともできます。取り込み時にコピーを作成するため、元ファイルとは別に同じ容量の空きが必要です。[PC変換ガイド](OBB-BUILDER.md)をご覧ください。
