# 마법사의 밤 — 비공식 Android 포트

[English](README.md) · 한국어 · [日本語](README.ja.md)

다양한 화면 크기와 화면비를 가진 휴대폰·태블릿·폴더블폰을 고려한 네이티브 Android 포트입니다. **PC 없이 휴대폰에서 Steam 게임을 직접 설치하고, 설치 후에는 완전히 오프라인으로 플레이할 수 있습니다.**

이 저장소와 배포 APK에는 원본 게임의 이미지·음성·영상·대사 데이터가 일절 포함되어 있지 않습니다. 게임 데이터는 정식으로 게임을 구매한 사용자의 Steam 계정을 통해 직접 다운로드합니다.

**[최신 APK 다운로드](https://github.com/david419kr/mahoyo-steam-android-port/releases/latest/download/mahoyo-unofficial.apk)**

## 준비물

- **마법사의 밤**을 소유한 Steam 계정
- Android 9 이상, OpenGL ES 3.0을 지원하는 64비트 ARM 기기
- 로그인·설치용 인터넷 연결과 약 **20GB의 여유 공간**. 필요한 공간은 앱에 표시됩니다.

### 실기 성능 참고

- Snapdragon 7 Gen 1, RAM 8GB 기기에서 60 FPS로 원활하게 작동했습니다.
- Dimensity 720, RAM 2.5GB 기기에서도 구동을 확인했지만, 이 정도 사양에서는 프레임 저하가 심하게 느껴집니다.

이는 테스트한 기기의 결과이며 최소 사양을 의미하지 않습니다. 성능은 기기와 장면에 따라 달라질 수 있습니다.

## Steam에서 설치하기

1. 휴대폰에 APK를 설치합니다. Android에서 요청하면 APK를 연 앱의 설치 권한을 허용합니다.
2. 앱을 열고 **QR로 로그인**하거나 Steam 계정 이름·비밀번호와 Steam Guard로 로그인합니다.
3. 소유권 확인이 끝나면 **Steam에서 바로 설치**를 누릅니다.
4. 다운로드와 게임 데이터 준비가 끝날 때까지 기다립니다.
5. **게임 실행**을 누릅니다.

설치 후에는 정기적인 Steam 재로그인 없이 **완전히 오프라인으로 플레이**할 수 있습니다. 다운로드가 중단됐다면 다시 로그인하고 **Steam에서 바로 설치**를 눌러 이어받으세요.

### 같은 휴대폰에서 Steam 인증기를 사용 중이라면

로그인 QR을 다른 화면에 표시할 수 있습니다.

1. **다른 기기에 QR 표시**를 누르고, 표시된 주소를 PC·태블릿·다른 휴대폰의 브라우저에서 엽니다.
2. 두 기기는 같은 Wi-Fi 또는 같은 공유기의 유선 LAN에 연결되어 있어야 합니다.
3. 휴대폰에서 **Steam 인증기 열기**를 누른 뒤 다른 화면의 QR을 스캔하고 로그인 승인을 완료합니다.

QR은 자동으로 갱신됩니다. 공유 버튼 옆의 **?**에서도 안내를 볼 수 있습니다.

### 한글패치 추가 설치

Steam 설치를 마친 뒤, 직접 준비한 한글패치 ZIP을 별도로 적용할 수 있습니다. (이 안드로이드 포트에 한굴패치는 포함되지 않습니다.)

1. 설치 화면에서 **한글패치 ZIP 적용**을 누릅니다.
2. 지원되는 한글패치 ZIP을 선택합니다. ZIP 내부의 필요한 파일은 자동으로 검출됩니다.
3. **한글패치 적용 완료**가 표시되면 게임을 실행합니다.

적용에는 ZIP 외에 약 **2.5GB의 추가 여유 공간**이 필요합니다.

## 조작 방법

| 조작 | 기능 |
| --- | --- |
| 탭 | 대사 진행 |
| 두 손가락 탭 | 메뉴 표시·숨김 |
| 아래로 스와이프 | 이력 |
| 위로 스와이프 | 설정 |
| 오른쪽으로 스와이프 | 저장 |
| 왼쪽으로 스와이프 | 불러오기 |
| 1초 이상 길게 누르기 | 손을 뗄 때까지 스킵 |

메뉴는 반대 방향 스와이프로 닫습니다. 대화창이나 메뉴에 스크롤이 있으면 끝까지 스크롤한 뒤 더 밀어 주세요. 메뉴를 열다가 되돌리는 방향으로 움직여 놓으면 취소됩니다.

**설정 → 화면**에서 원본 16:9·동적 화면, 이미지 전체 표시·꽉 채움, 전체화면·하단 분리 대화창을 선택할 수 있습니다. 대화창 **자동**은 사용 가능한 화면 공간에 맞춰 배치합니다. 글자 크기와 좌우 여백도 조절할 수 있습니다.

이력의 되감기 버튼을 누르고 확인하면 해당 대사 장면으로 돌아갑니다. 기존 저장에 남은 이력도 대상이며, 저장 파일은 덮어쓰지 않습니다. 복원에는 잠시 시간이 걸릴 수 있고, 복원 지점을 검증하지 못하면 현재 진행을 유지합니다.

세이브는 기기에 저장됩니다. 앱을 삭제하거나 앱 저장공간을 지우면 설치 데이터와 세이브도 삭제됩니다.

게임 제작·유통사 및 Valve와 무관한 비공식 프로젝트입니다. 게임 파일은 본인의 Steam 계정으로 내려받습니다.
